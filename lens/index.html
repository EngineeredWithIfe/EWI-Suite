EWI Lens

On-device OCR and visual analysis that turns images into structured, searchable, editable text.

Run the EWI Lens engine

In a terminal, from your EWI Suite folder, run:

cd ewi-lens && python3 serve.py

Then open localhost:8720 in your browser.

EWI Lens runs real on-device OCR and visual-analysis models — computer-vision work that lives in a local engine, beyond what a static web page can do on its own. Launch it locally in one step above to turn images into structured, searchable, editable text.
