Browser Cloud

A real, automatable browser you can drive programmatically — navigate, capture and script the open web.

Run the Browser Cloud engine
cd working-samples/01-browser-cloud
python3 server.py
# then open http://localhost:8701

Browser Cloud drives a real, automated web browser — software that has to run on a machine of its own, not inside another web page. A static site like this one has no way to launch it, so the full engine runs locally in one step below.
