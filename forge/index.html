    Foundry — guide

    A compact 3D content-creation studio with a software renderer. Everything runs in your browser; nothing is uploaded.

    Navigate the viewport

    Drag to orbit, Shift+drag to pan, scroll to zoom. Click an object to select it.

    Model

    Add primitives from the left. Edit location, rotation, scale, color and roughness on the right. Subdivide increases resolution; Smooth relaxes the mesh (a simple sculpt), Displace adds procedural detail.

    Shade & render

    Switch Wire / Solid / Material in the viewport. Render adds a soft floor shadow and a polished background. Tune the Sun (azimuth, elevation, strength, ambient) on the left.

    Export

    Export OBJ downloads the whole scene as a Wavefront .obj (open it in Blender, a game engine, or a 3-D printer slicer). Save PNG captures the viewport.

    Keyboard

    X delete · D duplicate · F frame all · 1/2/3 wire/solid/material · Z ground toggle.
