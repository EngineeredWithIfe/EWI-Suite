EWI Stat — guide

EWI Stat is a full statistics workbench. Everything runs in your browser.

Enter data

Type into Data View (rows = cases, columns = variables) or load a sample dataset / Import CSV from the Data menu. Define types and measurement level in Variable View.

Analyze

Descriptives, Frequencies, one-sample / independent / paired T tests, one-way ANOVA, Pearson & Spearman correlation, multiple linear regression, and crosstabs with a χ² test — each producing publication-ready tables with exact p-values, effect sizes and a written summary.

Graphs & export

Histograms, boxplots, bar charts and scatterplots render to the Output viewer. Export output saves a self-contained HTML report of everything you have run.
