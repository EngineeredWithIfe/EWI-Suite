EWI Matrix — language reference

A compact matrix and array language that runs entirely in your browser. No files leave your Mac.

Values & construction

3.14, 1e-3, row [1 2 3], matrix [1 2; 3 4], range 1:10 or 0:0.5:pi, strings 'hello'.

Operators

+ - * / (matrix), .* ./ .^ (elementwise), \ left-divide/solve, ' transpose, comparisons == ~= < > <= >=, logic & | ~.

Built-ins

zeros ones eye rand randn linspace magic reshape repmat diag · size length numel · sum prod mean median std var min max sort cumsum · inv det trace norm dot cross rank · sin cos tan exp log log10 sqrt abs sign floor ceil round mod · pi e eps Inf NaN.

Graphics

plot plot3 scatter bar stairs stem · surf mesh contour · hist · title xlabel ylabel zlabel legend grid hold clf figure.

Keyboard

Command Window: Enter run · ↑ / ↓ history · clc clears the log. Editor: Ctrl/⌘+Enter runs the script.
